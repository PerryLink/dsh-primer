# Legacy `dsh-plugin-guide@0.3.42`

`0.3.42` was the last npm release of the old agent-skill/CLI line. npm versions
cannot be moved between packages, so the published tarball remains available at:

- https://www.npmjs.com/package/dsh-plugin-guide/v/0.3.42

The old code is also preserved in this repository's history. The live skill is
now `dsh-primer`; see `MIGRATION.md`.

The name `dsh-plugin-guide` is being reused for a **different** product: the
0.4.0 prose guide and guide skill. Do not treat 0.4.0 as a compatible update of
0.3.42.
